# hometownkart.bitscience.ai

The website of Hometown Kart, served by GitHub Pages at https://hometownkart.bitscience.ai (a CNAME record at
GoDaddy points the subdomain at `brokenlink32.github.io`).

- `index.html` – the landing page.
- `404.html` – any other address.
- Coming with the game's 1.3.0 links (see the design doc): `/.well-known/assetlinks.json` (Android App Links),
  `/r/` room invites, `/f/` friend links and the password-reset page.

The legal pages (privacy policy, support, account deletion) stay at
https://brokenlink32.github.io/dev404system-legal/hometown-kart/.
